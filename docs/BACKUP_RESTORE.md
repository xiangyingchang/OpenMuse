# 备份、导出与恢复

更新：2026-10-12。

## 必须遵守的产品要求

用户会持续使用 OpenMuse。聊天、记忆文件、目标、任务过程和已保存成果都是重要资料，不能因应用升级、设备更换或自动清理而随意丢失。用户应能随时创建一份完整备份，也能把资料导出到自己选择的位置，并在需要时导入恢复。备份与恢复属于长期使用的基础能力，不是迁移时才临时提供的工具。

当前备份写入用户在文件选择器中选定的文件夹；用户可以选择 iCloud Drive。OpenMuse 不把正在使用的 SQLite 数据库直接放进 iCloud，也不因此获得两端实时同步。iCloud 文件上传和下载仍由系统处理，可能需要等待网络和系统调度。

## 包含内容与格式

手动“立即备份 / 导出”和定时备份都生成未加密的标准 ZIP。包中包含：

- `memory/` 下的工作区 Markdown 文件副本，包括 `SOUL.md`、`USER.md`、`MEMORY.md`、`GLOBAL.md`、`HEARTBEAT.md` 及其他工作区文档；
- `workspace.zip` 中的完整工作区记录、修订和冲突，包括聊天消息、活动、目标、结构化记忆、构件、提醒、任务与 Agent 任务草稿；
- 聊天附件原件、构件所引用的图片等素材，以及用于校验和恢复的清单与摘要。
- 对话专属 Agent 任务工作区中的持久草稿文件。

外层 `README.md` 说明包的结构和读取方式。其他 AI 或普通解压工具可直接读取 `memory/` 中的 Markdown；完整记录采用 `workspace.zip` 中的版本化清单和 JSONL 数据。若 AI 不支持读取 ZIP，应先解压并按 README 查看，不需要专用解密工具。

备份不包含 API 密钥、邮箱密码等凭证，也不包含 iSH 系统目录、端侧临时运行区（`AgentRuntimeSessions`）、浏览器 Cookie/缓存等设备状态。所选模型端点、自动备份时间和备份目录也属于本机设置，不随工作区包迁移。用户保存在 iSH 系统目录或临时运行区的文件不会随备份迁移；请将需要长期保留的资料保存到 OpenMuse 工作区文档、构件或对话专属 Agent 任务工作区。更换设备后需要重新配置凭证并重新选择备份目录、设置备份时间。未导入 OpenMuse 工作区的外部原始资料也不会凭空进入备份。

当前工作区恢复包的大小上限约为 50 MB；超过上限会明确报错，不会显示备份成功。大附件或长期积累的聊天可能达到上限，后续需要根据实际使用评估分卷或增量方案。

## 手动导出与定时备份

- 手动导出在用户点击时创建一份带日期和唯一编号的新文件；自动清理不会删除手动导出。
- 定时备份支持每天指定本地时间。默认关闭；启用后默认时间为 21:00。
- 定时备份默认保留最近 7 份，可设为 1–30 份。轮换只处理 OpenMuse 创建的定时备份文件，不处理手动导出、用户其他文件或旧命名备份。
- Mac 在 App 运行时检查到期任务。iPhone 依赖 iOS 后台刷新窗口；系统可以延迟或不提供窗口。重新打开 App 时会补查。因此定时备份是便利措施，不能替代用户主动导出和检查文件是否已到达 iCloud Drive。
- 定时备份失败会显示最近结果；设置备份后应确认目标文件夹中出现了新文件。不要仅凭开关已开启就认定备份成功。

## 导入与恢复

在“备份与恢复”中选择整个 ZIP，查看导入预览后再确认。OpenMuse 校验包和内容摘要，并将记录合并进当前工作区；不会静默覆盖本机版本。重复导入会识别已导入记录，版本冲突会保留并显示供用户处理。向新设备恢复时，可先安装并打开 OpenMuse，再从备份文件导入；API 密钥需要在新设备重新设置。

导入会按 JSON 内容比较记录、历史修订和冲突两侧数据，不把字段排列顺序变化当作内容变化；内容完全相同的重复历史修订和误报冲突会合并或移除，内容不同的真实冲突会保留。

导入可恢复 OpenMuse 持久化工作区资料，不会恢复被排除的 Keychain 凭证、iSH 系统/临时运行环境或浏览器会话状态。若系统在记录导入后、任务草稿文件恢复前发生文件错误，界面会说明部分结果；修复文件访问后可以再次导入。

## 隐私与遗忘边界

按用户决定，备份不做 OpenMuse 专用加密，方便用户用其他工具和 AI 阅读。包可能包含完整聊天和个人记忆；OpenMuse 不会自动上传或发送。是否把 ZIP 交给其他 AI、保存到共享文件夹或发给他人，由用户决定。

用户手动导出的文件属于用户控制的副本。OpenMuse 的“忘记”操作不会远程删除这些副本；用户应自行找到并删除仍不希望保留的旧导出。自动定时备份的轮换只按保留份数删除旧定时文件，目前没有按某条记忆定点清除备份的能力。
