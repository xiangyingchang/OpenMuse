# OpenMuse 应用图标

## 概念稿 v1

![OpenMuse 图标概念稿](OpenMuse-AppIcon-Concept-v1.png)

以两道相向弧形围住一颗星，表达一个有自己连续性、也为用户留有空间的陪伴者。深靛蓝底色和柔和的暖光让图形在主屏幕与 Dock 上保持辨识度；图形和颜色均为 OpenMuse 原创，不使用 Muse 的应用图标或私有资产。

## 概念稿 v2（候选）

![OpenMuse 图标概念稿 v2](OpenMuse-AppIcon-Concept-v2.png)

在 v1 的“陪伴环 + 中心微光”方向上收简图形，改为单一开放圆环和中心暖色星点，减少细节，让小尺寸下更易辨认。图稿为满版方形底色，正式 App 图标应继续由 iOS 和 macOS 自己裁切圆角。v2 暂作候选，尚未替换已接入的 v1；确定采用后再生成双端尺寸并检查主屏幕与 Dock 显示。

## 概念稿 v3（候选）

![OpenMuse 图标概念稿 v3](OpenMuse-AppIcon-Concept-v3.png)

在开放环形里加入一条向前延伸的光路，中心微光代表陪伴者，逐渐汇聚的轨迹代表共同积累的记忆与持续成长。深靛蓝背景和暖色光保留 v1、v2 的识别方向。原稿为 1254×1254；目前仅作为设计候选，尚未接入 iOS 或 macOS 图标资源。

## 概念稿 v4（候选）

![OpenMuse 图标概念稿 v4](OpenMuse-AppIcon-Concept-v4.png)

沿用靛蓝与暖金色调，收减背景星点和光路层次，让开放环、中心微光在小尺寸下更突出。原稿为方形全幅图；目前仅作候选，未替换双端已接入图标。

## 已接入版本

- iOS：`Apps/iOS/Assets.xcassets/AppIcon.appiconset`，1024×1024 单一图标源。
- macOS：`Apps/macOS/Assets.xcassets/AppIcon.appiconset`，提供 16–1024 像素的 Retina 尺寸。
- 两端使用同一概念稿，各自通过平台专属 Asset Catalog 接入；应用工程的 AppIcon build setting 指向 `AppIcon`。
- 原始概念稿保存在本目录，平台尺寸文件由它生成。更换设计时保留旧稿并新增版本，不覆盖历史资产。

当前图案已进入双端构建资源；运行中的 Dock / 主屏幕显示仍以最终安装包和设备检查为准。

## 概念稿 v5（候选）

![OpenMuse 图标概念稿 v5](OpenMuse-AppIcon-Concept-v5.png)

以单一开放环和中心四角微光作为识别符号：开放处呼应持续对话，连续环表达长期陪伴，中心光点表达适时的启发。使用深靛蓝底与暖金、浅桃色渐变，采用更简洁的轮廓，避免细小装饰；原稿为 1254×1254 方形全幅图。缩至 32×32 像素后，开放环和中心光点仍可辨认。此稿为候选，尚未替换 iOS 或 macOS 图标资源。

## 概念稿 v6（候选）

![OpenMuse 图标概念稿 v6](OpenMuse-AppIcon-Concept-v6.png)

以开放圆环、中心暖光和向上舒展的双弧构成一个抽象陪伴者形象，表达在场、成长与引导；深靛蓝底色搭配暖金、珊瑚色和少量紫色。原稿为 1254×1254 方形全幅图，由内置图像生成工具生成。此稿为新候选，尚未替换双端 AppIcon 资源，也未做设备图标验收。

## 概念稿 v7（候选）

![OpenMuse 图标概念稿 v7](OpenMuse-AppIcon-Concept-v7.png)

以一条粗而连续的开放弧环住一枚暖光，表达持续在场和给用户留出空间。与 v1–v6 的中心星芒方向区分，本稿不使用星点、人物或文字；深靛蓝底色与克制的紫暖渐变保持 OpenMuse 已有色彩方向。原稿为 1254×1254，由内置图像生成工具生成；已检查 32×32 与 16×16 缩图，主要轮廓和暖光仍可辨。此稿仅供评审，未替换 iOS 或 macOS AppIcon。

## 概念稿 v8（候选）

![OpenMuse 图标概念稿 v8](OpenMuse-AppIcon-Concept-v8.png)

以一条连续的柔和光带形成微启的门廊，门内暖光表达稳定在场和可进入的陪伴空间。保留深靛蓝、薰衣草紫与暖白配色；不使用文字、星芒或人物符号，并让主轮廓占据较大面积以适配小尺寸。原稿为 1254×1254，由内置图像生成工具生成；32×32 与 16×16 缩图中门廊主轮廓仍可辨。此稿仅供评审，尚未替换 iOS 或 macOS AppIcon，也未验证设备上的圆角裁切效果。

## 概念稿 v9（候选）

![OpenMuse 图标概念稿 v9](OpenMuse-AppIcon-Concept-v9.png)

用一条未闭合、非对称的连续弧线表达长期对话与持续成长：暖色起点转向薰衣草色的抬升弧线，中间的留白代表用户仍有自己的空间。采用深靛蓝满版底色，不含文字、人物、星芒或闭合环形。原稿为 1254×1254；32×32 和 16×16 缩图中主弧线仍可辨。此稿是候选，尚未替换 iOS 或 macOS AppIcon，也未验证设备上的圆角裁切效果。
