# 从其他 AI 带回对你的了解

日期：2026-10-10。用户已提供并指定预埋提示词；目前保存为设计资产，没有实现 App 导入功能。

## 预埋原版

[提示词 v1](../prompts/memory-transfer.v1.md)逐字保留用户提供的内容，不添加界面说明或擅自翻译。复制按钮应只复制文件正文。未来若调整，另建新版本，保留原版与修改理由。

提示词要求按十类标题输出、每条一个句子、用第三人称、标记不确定推断、略过没有可靠信息的分类、避免普通一次性信息、限制敏感内容，最多 2000 英文词。内容来自其他 AI 的既有对话；本功能不会自动获取其他服务账号或历史。

## 建议入口和流程

第一次使用可以跳过；获得一次实际帮助后，自然提示“如果其他 AI 已经很了解你，可以把它知道的带过来”。设置和记忆页长期提供“从其他 AI 导入”。

1. 复制原版提示词，用户自行发给原来的 AI。
2. 用户检查回复，再粘贴或选择 Markdown 文件带回。
3. 展示原文与提取条目，允许取消、删改、选择保留项；空分类无需补全。
4. 按主体、事实/推断、当前/可能过期、重复/冲突整理候选；没有标记 inferred 不等于已经证实。
5. 用户选择导入后，经过同一记忆事务提交，显示新增、更新和暂未采用的结果。
6. 以自然对话澄清影响当前任务的缺口，不因资料不完整阻止聊天。

导入预览为当前建议，未把提供提示词解读成对全部导入规则的最终批准。原文“verbatim”表示便携输出的目标；OpenMuse 建议保留原文作为来源，不将全部内容直接拼进系统提示或覆写 USER.md。

## 与长期记忆的连接

每次导入保留 importId、提示词版本、接收时间、原文引用、可选的来源 AI 和来源时间；未知信息留空，不把接收时间当成事实发生时间。不要求其他 AI 使用相同模型或内部记忆格式。

明确偏好、个人事实与长期项目成为带来源候选，USER/GLOBAL 使用统一记录的精简视图；推断保留标记。关系信息绑定对应人物，不当成用户事实。导入项目不自动启用目标跟进、提醒或外部动作。

重复导入先去重；与用户当前纠正冲突时不自动覆盖。导入文本属于资料，不能编辑 SOUL、AGENTS、HEARTBEAT 或增加工具权限。原文中若混入指令，也不得按指令执行。

原提示词已要求跳过部分敏感信息；“用户曾向另一个 AI 要求记住”不等于已在 OpenMuse 确认保留。预览阶段仍可删除。健康段落的“用户自己说过”条件也不取消前面的敏感信息规则。这里只描述产品处理原则，不改写原提示词。

原文与解析记录仅保存在用户本地/所选同步范围，不进入公开仓库。取消不产生有效记忆；正式导入可按批次撤销，已经被用户后续修订的条目不能被整批回滚误删。彻底遗忘还要清理对应原文和派生内容，详见 [核心存储方案](MEMORY_STORAGE.md)。

## 未来实现的验收

- 复制结果与 v1 文件正文一致，保留引号、分类与换行；不混入 UI 说明。
- 省略分类、空回复、超长输入和自由 Markdown 都有清楚结果，不编造缺项；输入限制由客户端另外定义，不能假定原 AI 一定遵守 2000 词。
- inferred 标记、来源和原文可追溯；过期与冲突不静默覆盖当前理解。
- 重复导入不重复新增；取消、撤销与遗忘有真实可见结果。
- 导入不会修改人格/权限或自动启动项目；换模型后仍可使用相同结构化记忆。

上述为验收设计，尚未执行 App 测试。
