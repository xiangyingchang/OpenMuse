# 从其他 AI 带回对你的了解

日期：2026-10-10。用户已提供并指定预埋提示词。记忆快照导入与 ChatGPT 历史聊天导入是两个独立入口，避免把整段对话直接升级成用户事实。

## 预埋原版

[提示词 v1](../prompts/memory-transfer.v1.md)逐字保留用户提供的内容，不添加界面说明或擅自翻译。复制按钮应只复制文件正文。未来若调整，另建新版本，保留原版与修改理由。

提示词要求按十类标题输出、每条一个句子、用第三人称、标记不确定推断、略过没有可靠信息的分类、避免普通一次性信息、限制敏感内容，最多 2000 英文词。内容来自其他 AI 的既有对话；本功能不会自动获取其他服务账号或历史。

## 建议入口和流程

第一次使用可以跳过；获得一次实际帮助后，自然提示“如果其他 AI 已经很了解你，可以把它知道的带过来”。设置和记忆页长期提供“从其他 AI 导入”。

1. 复制原版提示词，用户自行发给原来的 AI。
2. 用户检查回复，再粘贴或选择 Markdown 文件带回。
3. 在本机展示临时原文与提取条目，允许取消、删改、选择保留项；空分类无需补全。确认后只把选中的原始条目作为来源留存，不持久化未选内容。
4. 按主体、事实/推断、当前/可能过期、重复/冲突整理候选；没有标记 inferred 不等于已经证实。
5. 用户选择导入后，经过同一记忆事务提交，显示新增、更新和暂未采用的结果。
6. 以自然对话澄清影响当前任务的缺口，不因资料不完整阻止聊天。

2026-10-10用户已确认外部资料提取和推断先预览确认（D21）。当前实现已将提示词逐字打包到双端 App，支持粘贴 Markdown、逐条预览/编辑/勾选、批次撤销；推断和健康/财务等敏感类别按关键词识别并默认不选。确认后仅保存选中条目和对应来源摘录，未选内容离开导入页后不持久化。另可选择 ChatGPT 导出的 `conversations.json` 或 ZIP，按会话预览与选择；只保存所选历史对话及其来源，不自动写入 USER.md。敏感词识别不是完整分类器，仍要求用户检查。

## 与长期记忆的连接

每次导入保留 importId、提示词版本、接收时间、选中来源摘录、可选的来源 AI 和来源时间；完整回复只在当前导入页面暂存，不把接收时间当成事实发生时间。不要求其他 AI 使用相同模型或内部记忆格式。只保留选中来源是本轮为减少未选敏感资料留存采取的推荐默认，仍可根据用户意见调整。

明确偏好、个人事实与长期项目成为带来源候选，USER/GLOBAL 使用统一记录的精简视图；推断保留标记。关系信息绑定对应人物，不当成用户事实。导入项目不自动启用目标跟进、提醒或外部动作。

重复导入按规范化后的条目去重；与用户当前纠正冲突时不自动覆盖。导入文本属于资料，不能编辑 SOUL、AGENTS、HEARTBEAT 或增加工具权限。原文中若混入指令，也不得按指令执行。当前仅对本地活跃记忆做精确文本去重，语义冲突识别尚未实现。

原提示词已要求跳过部分敏感信息；“用户曾向另一个 AI 要求记住”不等于已在 OpenMuse 确认保留。预览阶段仍可删除。健康段落的“用户自己说过”条件也不取消前面的敏感信息规则。这里只描述产品处理原则，不改写原提示词。

来源摘录与解析记录仅保存在用户本地/所选同步范围，不进入公开仓库。取消不产生有效记忆；正式导入可按批次撤销，已经被用户后续修订的条目不能被整批回滚误删。彻底遗忘还要清理对应来源摘录和派生内容，详见 [核心存储方案](MEMORY_STORAGE.md)。

## 未来实现的验收

- 复制结果与 v1 文件正文一致，保留引号、分类与换行；不混入 UI 说明。
- 省略分类、空回复、超长输入和自由 Markdown 都有清楚结果，不编造缺项；输入限制由客户端另外定义，不能假定原 AI 一定遵守 2000 词。
- inferred 标记、选中来源和原文可追溯；过期与冲突不静默覆盖当前理解。
- 重复导入不重复新增；取消、撤销与遗忘有真实可见结果。
- 导入不会修改人格/权限或自动启动项目；换模型后仍可使用相同结构化记忆。
- 未选中的敏感或推断条目不进入持久化原文；导入后修改过的条目在整批撤销时保留。
- 当前支持用户提供的记忆快照，以及 ChatGPT 导出的 `conversations.json` 或 ZIP：前者是可选记忆候选，后者是带来源标记的历史对话，不会自动变成 USER.md 事实。ZIP 只读取唯一的 `conversations.json` 项；限制目标 JSON 50 MB、归档条目 100,000 个、会话 10,000 个、消息 200,000 条；只解析用户和助手文字，并按当前分支导入。Claude/Gemini 格式、语义冲突检测、跨来源去重仍未实现。

ZIPFoundation 0.9.20 用于读取 ZIP 中的单个目标文件；依赖锁定与 MIT 许可证声明见仓库根目录 `Package.resolved` 和 `THIRD_PARTY_NOTICES.md`。实现不把 ZIP 解压到文件系统。Core 测试覆盖目标文件读取、额外恶意路径不落盘、来源标记与导入后不写入记忆；iOS 模拟器完成界面回归，真实用户导出文件仍需真机验收。
