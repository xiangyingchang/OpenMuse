## 1. 整体结构与视觉

当前暗色外观：黑底、深灰圆角内容、蓝色用户消息/主要行动、半透明浮动控制。顶部圆头像与名称是持续人格的入口，左侧圆形导航按钮，右侧邀请入口。底部独立胶囊导航含聊天、动态、点子、目标、资源库；图标为主，辅助功能有明确名称。顶部与底部采用浮层/模糊效果，内容可滚到其下。

侧栏将主体向右让位，有 Muse 标题、设置、可折叠标签页、旁聊区域、搜索和新建入口；空旁聊有说明。界面提示支持长按调整标签顺序，未操作验证。头像信息为全屏式面板，包含头像、名字、连接状态和五段切换：活动、批准、桌面端、近期、身份。

## 2. 聊天、输入与引用

主聊气泡：用户蓝色靠右，助手深灰靠左；支持多段文本、强调与 emoji 反应。底部输入为圆角胶囊，左附件、右语音/发送，浮在底部标签栏上。观察到了历史聊天的滚动，没有发送新消息，不将历史回复作为本次推理测试。

动态“讨论”进入主聊，自动聚焦输入并打开键盘，在输入上方显示“正在回复 Muse”的来源预览，可点 X 取消引用。取消后没有发送内容。实际键盘属于用户输入法，不能作为 Muse 自带键盘设计。流式生成、语音录制/转写、消息长按、发送失败与离线发送仍待测试。

附件按钮打开媒体选择面板，照片缩略图、相机、查看全部、添加文件和视频入口。未选择、拍摄、上传或读取附件；媒体缩略图截图严格留本地。

## 3. 目标

列表以进行中与已完成区分，有可展开的父目标、进度摘要、缩进子目标、复选框和各项菜单。已完成行使用勾选/弱化样式。详情含标题、描述、构件折叠区域、子目标和动态时间线。未改变完成状态或执行目标菜单。

设计含义：目标不是只有标题的待办；与成果、子步骤、后续工作记录相连。自动发现、计划调整、目标状态转移不能由静态页面证明，需后续旅行案例验证。

## 4. 动态

顶部有动态指令预览及编辑入口；下方内容包含 emoji、标题、段落、来源链接、横向图片、喜欢、讨论、时间与信息按钮。已验证讨论带来源进入聊天，并可取消引用。未保存指令、点赞或打开推荐理由详情；这些动作的效果与后续推荐变化仍待核对。

## 5. 点子

列表呈现 emoji、标题与为何适合的描述；详情为底部面板，背景变暗，含说明、“包含哪些内容”成果清单、蓝色“开始吧”与菜单。菜单显示开始、更多类似内容、不感兴趣。没有启动点子或提交反馈。

设计含义：先展示可能获得的成果，让用户决定开始；点子接受后的目标/任务关联与运行状态未知，不可凭按钮名称断言。

## 6. 资源库

分段为构件与影音内容。构件列表可进预览，内容可以是独立富网页，其排版/配色并非主 App 样式。加载时有等待状态；一次预览的部分图片占位仍缺失，不代表整个页面失败。构件操作菜单有置顶、分享、下载、删除，未执行。

影音内容采用媒体网格，先占位后加载；有图片、视频和音频等内容。未播放或打开私人媒体。需后续核对生成、更新、分享、导出、删除后的行为。

文件以阅读面板展示，顶部关闭、编辑与更多入口。About this file 为界面解释，明确不属于文件正文。SOUL 展示人格价值和习惯；MEMORY.md 有精选长期记忆正文，包含事实、偏好与变更信息。

MEMORY 的界面说明表示会话开始读取、夜间维护，也说明可能过时、用户可编辑或要求忘记。此处记录产品声明；没有观测到实际夜间维护触发和具体加载算法。公开记录不复制用户记忆或 Muse 全部提示词。

OpenMuse 影响：旧候选将 MEMORY 作为 GLOBAL 指针需修正；MEMORY 应提供正文，与 USER/GLOBAL 的结构化来源保持一致。不能由 Muse 仅展示两个文件推断它内部不存在其他文件。
