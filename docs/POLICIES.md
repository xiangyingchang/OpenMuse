# 主动工作、成本、旁聊与遗忘默认方案 v1

2026-10-10。D21记忆规则已确认；下列具体数值为本轮制定的可调默认值，尚非用户明确批准的固定偏好，不按社区夜间周期机械复制。

## 主动工作与成本

| 工作 | 默认频率/条件 | 通知 |
|---|---|---|
| 会话记忆 | 重要明确事实随回合持久化；普通闲聊不每句造记忆 | 日常更新不逐条打扰，变化列表可查看；SOUL每次改动告知 |
| 目标跟进 | 每目标24小时最多一次检查；无变化不产生催促；约定时间优先 | 每日主动通知合计最多2条，具体约定提醒/当前任务完成另计 |
| 兴趣动态 | 每日最多3条新内容，来源可靠且去重 | 默认只进动态，不逐条推送 |
| 点子 | 每日最多2个，已有未处理项优先复用 | 默认只进点子，有重要可行动变化再提醒 |
| Dreaming | 有新增交流/纠正时，每日最多一次；空输入跳过 | 默认安静；人格改动必须告知 |

Asia/Shanghai默认安静时段22:00–08:00（可改）；合并非紧急通知，保留应用内结果。计划漏跑只补最近一轮，过期新闻不重推；目标提醒改为询问是否仍相关。手机执行依系统机会，Mac连接时优先承接；无设备运行不会伪造维护成功。暂停某目标同时暂停相关跟进；全局暂停立即阻止新的主动回合。

成本以供应商实际usage及配置价格估算，不猜价格。设置前先选供应商/模型并测试一次（用户主动）；主动模型调用需启用预算。建议首次预算为每天最多20次后台模型请求、每维护任务最多3次、2次只读重试；用户另填日/月货币上限。价格未知时显示token/请求统计，不能宣称金额硬上限有效；未确认金额上限只开启请求额度模式，界面明确差别。

每次请求前预留最大输出token及估计输入成本，收到usage后结算；达到任一已启用上限暂停主动工作，用户主动聊天保留但先提示/允许确认追加额度。两端预算额度连接时分配，失联只花各自已有预留；无额度不后台调用。无法获usage的请求保留预留上界，避免重复失联花费。不因模型错误自动无限重试。

低电量模式/系统热状态异常时暂停非用户发起维护；已开始工作保存进度。耗电比较作为可运行版本后的优化项，不作开工前门槛；后台能否执行的真实性仍必须验证。

## 旁聊与记忆

一个身份、共享已确认事实/目标/构件；旁聊只带主题摘要、关联对象与必要检索，不复制全部其他旁聊。任务临时约束只用于该目标；未确认推断不进入全局。引用保留来源且不视作用户陈述。用户可选择某条内容不用于长期记忆；不把此选项误称供应商不接收内容。

敏感健康/财务/心理等信息默认不自动持久化为精选记忆，明确要求记住或预览选择后才提交；原聊天是否保存单独显示。外部提取统一预览；连人带事实必须确认主体。SOUL语气/习惯演化记录差异与原因，每次应用后应用内告知，安静时段不强推；核心目的与权限变化等用户明确决定。

## 纠正、撤销与忘记

纠正新增修订并重建当前视图/索引，历史仍可解释；撤销不抹除后续用户修改。忘记前展示范围：事实、相关原材料片段、日记/dreaming、构件及旧修订，用户可只停止使用或彻底删除。默认“忘记这件事”走彻底遗忘预览，避免一句话误删整封无关邮件。

本地先停检索与新提交，再清相关数据；保留仅含opaque ID/来源ID的抑制标记，无原文。离线设备显示待删除，重连先传播删除，再合并普通变更；旧任务候选不可复活。旧来源重新扫描受抑制；用户明确重新导入后才可解除。模型供应商已收到的内容不能本地撤回。

备份：只在迁移前生成受控加密快照，默认保留最近3份、最长7天；彻底遗忘清理受控快照中的对应数据，无法局部清理则删除含数据快照。用户手动导出的包不在应用控制范围，提示具体文件需自行处理。离线旧设备和旧包导入先核对删除标记；从旧包独立重建时没有新标记，不能保证获知原设备遗忘，因此明确显示备份日期与遗忘状态未知。

以上默认方案分别验收频率上限、安静时段、预算预留/失联额度、暂停立即生效、旁聊隔离、范围删除、旧包恢复和敏感内容确认。
