2026-10-10。本轮实际查看10张归档图，按用户指示直接以既有Muse页面和交互元素作为设计基线；用户明确要求尽可能像素级还原。此前只完成首屏比例调整，尚未完成逐页像素对照或原版动画还原。原始图仍私人，公开规格使用合成内容。设计遵循DESIGN_PRINCIPLES。

## 共用组件

iPhone：顶部侧栏按钮、居中圆形陪伴者头像及贴近头像下缘的名称胶囊、右侧本页操作；左右圆按钮与头像上缘接近对齐。任务状态通过头像状态反馈和活动详情呈现，不放固定陪伴标语。底部五入口胶囊导航，选中项有独立深色背景；黑/中性背景、灰色面板、蓝色动作作为深色基线，浅色采用语义色。字体跟系统，主要触控目标至少44pt，安全区/键盘不遮操作。卡片圆角、边距和字体先用统一token，实施时与本地图片逐页核对，不编造截图精确尺寸。

头像使用原创占位/素材；工作、等待、完成/空闲、失败/断开映射真实状态。拟定过渡150–250ms、减少动态效果时静态切换（项目候选值，不称Muse原参数）。等候不做假百分比。活动标题、阶段、时间统一数据源，详细记录按需展开。

## 状态与操作规格

每页覆盖正常、空、加载、失败/重试、待同步；执行另含等待用户/电脑/网络、系统暂停、取消待确认。错误给原因和可做动作并保留输入；不可用操作不靠颜色暗示。模型未配置先设置/测试，可跳过连接器但不能假装可发模型消息。首次轻松旅行按ONBOARDING_TRAVEL，不据现有账号图假定已见Muse注册流程。

审批页展示具体动作、资料范围、目标设备、确认/拒绝；拒绝产生有效记录，不继续动作。首期无自动支付/发信。电脑页以连接和任务控制为主，浏览器画面只有真实实现该工具后才显示；长期完整桌面不画成一期可用功能。

Mac采用同样五模块侧栏+详情，聊天中同一头像活动入口；长表/成果可开更宽详情，快捷键与原生窗口行为；Mac布局是本项目适配，现有iPhone图不能证明Muse Mac行为。

## 视觉与可用性验收

逐页看相应原图→合成旅行数据实现→同一设备/视口截图叠加或差异检查布局、控件大小、层级和间距；保存页面、状态、设备、构建版本与偏差，修正后复测。正常/加载/错误/键盘路径分别走。检查五入口、旁聊草稿、表格展开/宽表、取消保存、头像层级、返回位置、大字号/VoiceOver/减少动态效果。用户无额外说明能找到发消息、看任务、改记忆、打开成果四项入口；困惑记入迭代并修正。不为开工额外制作另一套脱离截图的高保真稿；这份规格+私人证据即初期界面基线，公开展示图实施时用合成素材生成。不同设备截图缩放、字体栅格和系统版本可能产生像素差异，应区分布局偏差与抗锯齿差异；当前尚无截图差异验收记录。

## 2026-10-10 首轮前端实现状态

已实现：iPhone 五入口底栏与可搜索侧栏、主聊/旁聊分组及独立草稿、头像入口与五页陪伴者面板、任务阶段/步骤记录、滚离底部后的追新按钮、目标步骤勾选和关闭、构件预览/编辑/版本恢复、可编辑动态指令及无来源空态、从现有目标生成并关联旁聊的点子卡片。头像当前是原创静态表情加真实工作状态光圈，不是 Muse 头像素材或动画复刻。

未完成：消息引用/附件/语音、真实动态来源与推荐/讨论反馈、个性化点子反馈、完整审批/近期任务、浏览器/桌面控制以及逐页真机、键盘、大字号和 VoiceOver 验收。动态和点子页面保留真实空态或从现有目标推导的建议，不能宣称完整 Muse 机制已对齐。最近一次代码实现、测试与模拟器证据见 ITERATIONS 对应日期记录；完整 V1 仍按 PHASE1_PARITY 验收。
